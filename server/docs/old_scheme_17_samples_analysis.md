## 五、相关性分析

### 停机速率 vs 最终尾量：相关系数 **0.892**（强相关）

```
停机速率越高          → 尾量越大
停机速率越低          → 尾量越小
```

这是整个实验中最显著的统计关系。震动还处于高速给粉状态时停机，后续落料量会显著增加。反之，如果在低速时停机，尾量就小。

### 最终质量 vs 尾量：相关系数 **0.522**（中等相关）

尾量是造成超量的主要因素，但并非全部原因。最终质量还受到以下因素影响：

- **粉末状态**：松散程度、堆密度一致性
- **窗口位置**：开口大小影响粉末下落阻力
- **称重延迟**：从发出停止命令到实际读数稳定之间的质量增量

---

## 六、关键结论

1. **核心问题：停机时速率过高**
   - 停机速率均值 47.1 mg/s，中位数 42.3 mg/s
   - 意味着从命令发出到粉末停止下落，还有约 0.3~0.5s 的延迟时间内以 >40 mg/s 的速度继续落粉
   - 导致尾量均值高达 30.8 mg，范围 0~110 mg

2. **超量是主要偏差方向**
   - 超量 >515mg 占 35.3%，欠量仅占 5.9%
   - 平均偏差 +14.3 mg，说明整体偏向超量

3. **尾量预测是改进关键**
   - 停机速率与尾量高度相关（r=0.892）
   - 若能根据当前速率准确预测尾量，可以在更合适的时机提前停机

4. **采样间隔较大**
   - 最大采样间隔均值 2.918s，在高速给粉阶段，2.9s 内可能已经多落了 >100mg
   - 提高采样频率是提升控制精度的前提

---

## 七、改进方向启示

| 问题 | 改进方向 |
|------|---------|
| 停机速率过高 | 增加精加阶段降速机制，在接近目标时强制降低给粉速率 |
| 尾量不可控 | 建立速率→尾量的预测模型，实现提前停机 |
| 采样间隔大 | 提高称重采样频率，或使用状态估计器在采样间隔内插值 |
| 超量为主 | 控制策略应偏向保守，目标定在 490~500mg 而非 500mg+ |
