# 膨润土高速尾料停机试验（2026-08-24）

## 试验目的

解决膨润土1000 mg加粉中，末段流速较高时等待两次预测确认导致多加约5–8 mg，以及原始质量达到990 mg后才强制停机、未计入在途尾料的问题。

## 本次修改

1. 通用反馈控制器增加两项默认关闭的可配置能力：
   - 高速预测停机可减少确认次数。
   - 预计最终质量超过安全偏移时立即停机。
2. 只有膨润土 `bentonite` 的三处专属配置启用：
   - `fast_predictive_stop_enabled: true`
   - `fast_predictive_stop_rate_mg_s: 20.0`
   - `fast_predictive_stop_confirmations: 1`
   - `projected_safety_stop_enabled: true`
   - `projected_safety_stop_offset_mg: 5.0`
3. 其他粉末缺少上述启用字段，继续使用原来的两次确认与990 mg原始质量硬停机。
4. 膨润土新日志算法版本标记为 `predictive-stop-v3-bentonite-fast-tail`；其他粉末仍为 `predictive-stop-v2`。
5. 80 Hz、22%、窗口300、固定尾料5 mg和粗/细/精流速均未改变，配置状态仍为 `draft`。

## 回退方法

1. 从膨润土三处JSON中删除本记录列出的5个启用字段。
2. 从服务映射和日志配置中删除对应字段，恢复固定的 `predictive-stop-v2` 版本标识。
3. 从反馈控制器删除新增设置、预计质量安全停机分支和高速动态确认分支。
4. 删除本次新增的对应测试；不要恢复或覆盖上述文件中的其他用户修改。

仅执行第1步即可停止膨润土使用新机制，控制器通用能力可保留且不会影响任何粉末。

## 验证标准

先做3次安全验证；若无欠量和异常停机，再累计完成10次。逐次均在990–1010 mg后，才允许把膨润土1000 mg配置改为 `validated`。

## 首轮批量验证作废与透传修复（2026-08-24 17:49）

批次 `disp-batch-1sets-20260824_174925-12fb44` 的三次结果为996、1009、987 mg，但日志仍显示 `predictive-stop-v2`、高速停机关闭、预测安全停机关闭。因此这三次属于旧逻辑，不计入新机制验证。

原因是单次配置解析与批量任务各自维护了一份控制字段列表，批量列表遗漏了5个新增字段。修复内容：

1. 正式配置解析结果加入5个新字段。
2. 批量入口不再复制控制字段列表，统一调用与单次入口相同的 `resolve_dispense_configuration()`，防止以后再次漏传。
3. 同时修复批量汇总：由“任意一次合格就把整组标为合格”改为“所有计划重复均合格才把整组标为合格”。该汇总修复应在停机试验撤回后继续保留。
4. 增加真实批量参数透传和逐次验收回归测试。
