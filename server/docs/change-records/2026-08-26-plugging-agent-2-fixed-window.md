用户因每次窗口调节发生程序报错，要求取消封堵剂2窗口调节。
本次关闭该粉末加粉过程的自动调窗，保留开始前到本次设定窗口的定位。

## 实际变更

仅修改封堵剂2控制配置的生效开关：`stall_recovery_enabled: true → false`。
已有 `position_feedback_enabled=false` 保持不变；此前已移除全部tail_pulse覆盖项。
因此：

- 卡粉时不再从p400扩到p425，也不再执行恢复出粉后的回窗。
- 普通常规窗口反馈、尾段缩窗及700 mg后的脉冲开关窗均不启用。
- 结束/取消/异常清理分支中的卡粉恢复回窗也被该开关关闭，不会再额外请求回到起始位置。
- 仅保留开始加粉前的起始定位；默认80 Hz/22%/p400。手动修改本次起始位置仍有效。

占空比闭环调整及25%上限、流量保持、预测停机、1000 mg的15 mg尾料补偿、
960 mg实测安全停振阈值、各质量档流速配置均未改变。
原卡粉观察时间、步长和p425上限保留为未启用参数，便于独立恢复，不再参与执行。
配置提示已更新，明确当前为不自动调窗模式。

## 注意与独立回退

关闭卡粉恢复后，不再有该机制的卡粉识别、扩窗重试及重试耗尽停机；
持续不出粉时可能等待到原有180秒总超时。操作人员发现卡粉应手动停止并安全检查，
