# 阶段一 0.1 g 加粉算法软件架构（初版）

## 1. 阶段一边界

阶段一的主目标为稳定完成 **0.1 g（100 mg）加粉**。支线目标是在不降低安全性和可追溯性的前提下，测出当前机械、粉体和称量系统可达到的常见精度极限。

本阶段按既定范围实施除抗扰动装置外的流程步骤。软件先解决可控、可验收、可复盘，再逐步提升精度。GPR 和贝叶斯优化不进入阶段一的生产控制链路。

此前技术方案中的 `10 mg` 作为通用微量场景说明；本项目阶段一的默认配方、阈值和验收指标应以 `100 mg` 目标量为基准，且全部可配置，不能写死在算法代码中。

## 2. 设计原则

- **实时安全优先**：超量、通信故障、互锁、超时的处理不依赖 ILC、卡尔曼滤波或任何预测结果。
- **分时尺度设计**：毫秒级控制执行器，秒级判断切段和尾量，任务间才更新学习参数。
- **先 L0 后学习**：L0 标定表是阶段一的可投产基线；ILC 先以影子模式评估，达到样本和稳定性条件后才受限启用。
- **实测质量为准**：预测仅用于提前停料和切段；最终验收只能使用称量模块稳定后的实测质量。
- **参数可追溯**：每个任务记录粉体、头型、配方、L0 版本、估计状态、动作命令和 ILC 建议值。

## 3. 总体架构

```text
配方/任务 API
       |
任务编排与安全状态机 ---------------------------------- 互锁/报警/人工暂停
       |
加粉控制协调器
  |              |                 |
L0 参数选择    段间状态估计       段内执行控制
  |              |                 |
参数仓库       卡尔曼尾量估计     电机/振动/门控适配器
  |              |                 |
ILC 影子学习 <- 过程事件与称量时序 -> AT8811C 称量适配器
       |
数据仓库 / 回放 / 验收报表
```

| 层级 | 建议模块 | 核心职责 |
| --- | --- | --- |
| 设备层 | `device_adapters` | AT8811C 读数与状态、给粉执行器、门控、传感器、互锁；只做通讯和命令确认 |
| 采样层 | `weighing` | 原始计数换算、质量时间序列、称量质量检查、稳定窗口判定 |
| 控制层 | `dispensing_algorithm` | L0 选型、阶段切换、尾量估计、脉冲策略、受限 ILC 建议 |
| 编排层 | `task_state_machine` | 任务状态、超时、重试、暂停、故障退出和人工接管 |
| 数据层 | `data` | 事件日志、参数快照、标定数据、ILC 样本、回放和验收统计 |

## 4. 算法按时间尺度分工

| 时间尺度 | 要解决的问题 | 阶段一主算法 | 输出 |
| --- | --- | --- | --- |
| 任务启动前 | 新粉体或样本稀疏时给出可用前馈 | L0 查表与线性插值 | 初始段动作量、阈值和安全边界 |
| 毫秒级，段内 | 电机、振动、门控动作稳定且可复现 | 执行器 PID/伺服或固定脉冲闭环 | 实际动作完成、超时/故障结果 |
| 秒级，段间 | 预测余粉落料，决定何时切段或停止 | 卡尔曼尾量估计 + 稳定窗口 | 预测最终质量、下一阶段或停料决策 |
| 任务完成后 | 消除重复任务中的系统性偏差 | 受限 ILC（初始为影子模式） | 下一次任务的候选 L1 前馈修正 |
| 多批次后 | 稀疏场景下的推荐优化 | L3 GPR，非阶段一范围 | 后续阶段候选参数 |

## 5. 阶段一状态机

```text
IDLE
  -> PRECHECK
  -> TARE
  -> L0_SELECT
  -> COARSE_FEED
  -> COARSE_SETTLE
  -> SLOW_FEED
  -> SLOW_SETTLE
  -> FINE_PULSE
  -> FINAL_SETTLE
  -> ACCEPT / REWORK / REJECT
  -> ARCHIVE
  -> IDLE

任意状态 --[互锁、超量、称量失效、执行器故障、超时]--> SAFE_STOP -> ARCHIVE
```

### 5.1 关键状态职责

| 状态 | 进入条件 | 动作 | 离开条件 |
| --- | --- | --- | --- |
| `PRECHECK` | 收到任务 | 检查 AT8811C 通讯、互锁、配方和标定系数 | 全部通过，否则安全退出 |
| `TARE` | 空载许可 | 只在受授权状态调用称量模块清零；等待稳定 | 稳定且接近零基线 |
| `L0_SELECT` | 已去皮 | 根据粉体、头型、目标量、环境和配方选择 L0 | 生成不可变参数快照 |
| `COARSE_FEED` | L0 可用 | 快速给粉至预留安全余量 | 达粗加停料阈值或故障 |
| `COARSE_SETTLE` | 已停止粗加 | 估计尾量，等待/采样称量 | 进入缓补或精加 |
| `SLOW_FEED` | 剩余量在缓补区间 | 低速给粉 | 达精加阈值或故障 |
| `FINE_PULSE` | 剩余量小 | 小脉冲 + 每脉冲后的称量判断 | 合格、无法安全补偿或超时 |
| `FINAL_SETTLE` | 已停料 | 硬件稳定标志 + 软件窗口判稳 | 质量验收 |

## 6. L0 参数表

L0 的行键建议为：

```text
powder_type + powder_batch + feeder_head + target_mass_bin + recipe_version
```

每行至少包含：

| 参数 | 含义 |
| --- | --- |
| `coarse_action` | 粗加动作量，例如电机步数、振动时长和门控时长 |
| `coarse_stop_margin_mg` | 粗加停止时保留的质量余量 |
| `slow_action_limit` | 缓补单次与累计动作量上限 |
| `fine_pulse_action` | 精加单脉冲动作量 |
| `fine_pulse_max_count` | 最大精加脉冲数 |
| `tail_model_seed` | 初始余粉均值、衰减时间和不确定度 |
| `settle_window_ms` | 最短静置时间与稳定窗口长度 |
| `hard_overweight_mg` | 硬性超量上限 |
| `max_task_duration_s` | 任务最长时长 |

新粉体采用同类粉体的最近 L0 条目做线性插值或保守降级：降低粗加量、扩大精加余量、禁止 ILC 自动更新。

## 7. 秒级尾量估计与切段策略

停止振动或关闭门控后，仍可能有在途粉末落到秤盘。阶段一使用低维卡尔曼滤波器估计“当前已上秤质量”和“待落料尾量”，而不直接把最新秤值当作最终质量。

### 7.1 推荐状态模型

定义估计状态：

```text
x = [m_scale, m_tail, drift]^T
```

- `m_scale`：当前已经稳定或正在稳定到秤盘的质量。
- `m_tail`：已停止给粉但预计仍会落下的质量。
- `drift`：短时称量漂移项。

观测为 AT8811C 换算后的质量 `z`。在每一个采样周期，用最新称量更新 `x`；在停料后让 `m_tail` 按标定的衰减模型趋近于零。控制器使用：

```text
m_final_pred = m_scale + m_tail
remaining_pred = target_mg - m_final_pred
```

决策规则：

- `remaining_pred <= coarse_stop_margin_mg`：停止粗加并进入静置估计。
- `remaining_pred <= fine_entry_margin_mg`：停止缓补并进入精加脉冲。
- `m_final_pred >= hard_overweight_mg`：立即停止所有给粉，进入故障或人工复核。
- 估计方差超过阈值：不允许放大给粉动作，只能延长静置或进入保守精加。

初版可使用 alpha-beta 滤波器验证数据和参数；接口保持为 `TailMassEstimator`，后续无缝替换为正式卡尔曼实现。

## 8. 段内执行控制

称量模块不承担执行器的毫秒级闭环。电机、振动器和门控各自应有可确认的动作接口：

```text
command(action) -> accepted -> running -> completed | timed_out | fault
```

- 电机转速/位置控制使用设备自身伺服或 PID；上层只下发受限动作量。
- 振动和门控以可标定的脉冲/时长为最小控制单位。
- 每段都有最大连续运行时间、最大累计动作量和停止确认。
- AT8811C 的硬件稳定标志仅用于抑制过早切段；软件不能在未稳定时把读数用于最终验收。

## 9. ILC 在阶段一的正确位置

ILC 不替代 L0，也不直接控制当前任务。它在任务归档后，用合格任务的最终误差评估下一次任务的前馈修正：

```text
e_k = target_mg - final_mass_mg
a_(k+1) = clip(a_k + alpha * e_k / gain_hat, a_min, a_max)
```

`a` 为粗加与缓补的总有效动作量，`gain_hat` 来自 L0 标定或近期有效任务。阶段一采用以下发布策略：

1. **L0 投产**：所有任务执行已审批的 L0，不自动学习。
2. **ILC 影子模式**：记录 ILC 推荐动作量，但不下发；比较它与 L0 和实际误差。
3. **受限启用**：同一参数组达到最小有效样本数，且误差趋势稳定后，人工批准 L1；每次更新限幅 5%-10%。
4. **自动冻结**：连续异常、粉体批次/头型/维护变更、误差恶化或计量标定变更时，退回 L0。

以下任务禁止进入 ILC 样本集：称量不稳定、CRC/通讯错误、人工干预、堵料/低流、超量、重试失败或无有效 `scale_mg_per_count` 的任务。

## 10. AT8811C 接入要求

阶段一的称量适配器已支持实时重量和状态读取。算法层必须遵守：

- 读取 `0x0001` 的 32 位原始重量与 `0x0003` 状态字；bit 8 为硬件稳定标志，bit 9 为零区标志。
- 以经过标准砝码确认的 `scale_mg_per_count` 将原始计数转换为 mg；未标定时只能采集数据，不得验收或训练 ILC。
- 每个采样记录原始计数、换算质量、状态字、接收时间、CRC 校验结果和配置版本。
- 称量异常或连续通讯失败后，禁止新的给粉命令并进入 `SAFE_STOP`。

## 12. 阶段一实现顺序与验收

1. 完成 AT8811C 标定、采样记录和稳定窗口实验，冻结 `scale_mg_per_count` 与基本噪声参数。
2. 完成 L0 参数表、执行器命令确认和安全状态机，不接入自动学习。
3. 实现粗加、缓补、精加、收尾静置及基础尾量估计，完成 100 mg 重复实验。
4. 接入 ILC 影子模式、任务回放和参数版本化，验证建议值是否改善误差。
5. 经人工批准后，在限幅和自动冻结条件下启用受限 ILC。

阶段一验收至少包含：100 mg 装样成功率、欠量率、过量率及最大过量、最终误差/重复性、平均耗时、稳定判定耗时、异常识别率、过程日志完整率和 ILC 影子建议的离线收益。
