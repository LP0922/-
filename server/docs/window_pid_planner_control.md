# WindowPidPlanner 控制方式说明

## 定位

一个 **窗口位置前馈 + PID 反馈修正** 的 **脉冲式加粉规划器**。每次决策产生一个有限持续时间的脉冲动作，完成后需重新称重再决定下一步。

## 控制流程

```
输入：当前质量、本次观测速率、历史状态
  ↓
① 尾量预测          rate × 0.2s，上限 6.0mg
② 阶段判定          按剩余质量选择 COARSE / SLOW / FINE
③ 前馈窗口          查标定表 (window ↔ rate) 取最接近目标速率的窗口
④ PID 修正          实测速率 vs 目标速率的误差 → PID 算出修正量
⑤ 最终窗口          = 前馈基准 + PID修正，四舍五入到 10 的倍数
⑥ 计算持续时间       = 预期质量 / 目标速率，限幅在[min, max]内
  ↓
输出：FeedAction (窗口位置, 固定80Hz, 固定占空比20%, 持续时间)
```

## 五阶段划分

| 阶段 | 剩余质量 | 目标速率 | 基础窗口 | 作用 |
|------|---------|---------|---------|------|
| COARSE | > 160 mg | 50 mg/s | 650 | 快速粗加，留160mg余量 |
| SLOW | 35~160 mg | 22 mg/s | 200 | 中速过渡，留35mg余量 |
| FINE | ≤ 35 mg | 6 mg/s | 100 | 慢速精加，一次完成 |
| RECOVERY | 任意 | 无 | 650+26%占空比 | 无流量时强力脉冲恢复 |
| SETTLE | 达到目标 | 停止 | - | - |

## PID 修正

PID 修正量限幅 `±80 units`，输出步长 `10 units`：

```
比例项：  3.0 × error
积分项：  0.25 × ∫error·dt       (限幅 ±120)
微分项：  0.8  × d(error)/dt
```

## 关键特性

| 特性 | 说明 |
|------|------|
| 控制模式 | **脉冲式**（加一次→称重→再决定） |
| 调节手段 | **窗口位置**（前馈 + PID 微调） |
| 频率 | 固定 **80 Hz** |
| 占空比 | 固定 **2000 permyriad (20%)**，RECOVERY 阶段升到 26% |
| 无流量恢复 | 速率 < 1 mg/s 持续 1.5s → 自动触发 RECOVERY 脉冲 |
| 尾量预测 | 简单外推：rate × 0.2s，上限 6mg |

## 与当前连续振动方案的对比

| 方面 | 当前连续方案 (DynamicRatePlanner) | WindowPidPlanner |
|------|-------------------------------|-----------------|
| 加粉模式 | 连续振动直到停止 | 脉冲式，每步称重确认 |
| 调节变量 | **频率** (10~80Hz) | **窗口位置** (100~700) |
| 控制算法 | Bang-bang + 死区 | **前馈 + PID** |
| 固定参数 | 占空比20%、窗口1200 | 频率80Hz、占空比20% |
| 有无流量恢复 | 无（超时报错） | 有（RECOVERY脉冲） |
| 模型利用 | 无 | 有标定曲线前馈 |
