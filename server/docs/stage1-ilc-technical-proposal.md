# 阶段一粉末装样 ILC 初版技术方案

## 1. 目标与范围

本方案面向 10 mg 级粉末装样。目标是在粉体、给粉头型、目标质量和环境条件相对稳定的重复任务中，通过迭代学习控制（ILC）持续修正前馈给粉参数，使最终质量逐步接近目标，并将欠量风险控制在可接受范围内。

阶段一的重点是建立可验证的 ILC 数据闭环，而不是引入 GPR、贝叶斯优化等高级模型。系统必须始终满足以下原则：

- 安全互锁、急停、通信异常和超量保护优先于算法输出。
- 单次任务的实时控制由状态机和硬约束负责；ILC 只更新后续任务的前馈参数。
- 未完成稳定判定、发生报警或人工中止的任务不得自动用于 ILC 更新。
- 对“绝对禁止欠量”的配方，最终验收前允许受控补偿，不以 ILC 预测替代实测称重。

## 2. 总体架构

```text
配方与任务输入
        |
任务状态机 <----------------------- 报警/暂停/安全互锁
        |
四段式实时控制 <---- 实时称重与稳定判定
        |
执行器命令（电机/振动/门控）
        |
过程数据记录
        |
批次 ILC 学习器 ----> L0/L1 前馈参数表 ----> 下一次任务
```

系统分为五个边界清晰的模块：

| 模块 | 职责 | 不承担的职责 |
| --- | --- | --- |
| 设备适配层 | 天平、给粉机构、传感器、互锁的通信与命令确认 | 工艺决策与学习更新 |
| 任务状态机 | 执行、暂停、重试、超时和安全退出 | 修改历史标定参数 |
| 实时控制器 | 四段切换、脉冲给粉、稳定判定、尾量等待 | 跨任务学习 |
| ILC 学习器 | 根据合格历史任务更新下一任务前馈量 | 覆盖安全阈值或直接驱动设备 |
| 数据层 | 原始记录、可追溯参数版本、训练样本和报表 | 对设备下控制指令 |

## 3. ILC 问题定义

一次装样任务记为第 `k` 次迭代。对相同或相近工况，定义：

- `r`：目标质量（mg）。
- `y_k`：稳定后的最终实测质量（mg）。
- `e_k = r - y_k`：最终误差；正值表示欠量，负值表示过量。
- `u_k`：本次任务使用的前馈动作参数向量。
- `d_k`：扰动特征，如粉体批次、头型、环境、初始余料状态、天平零点和执行器状态。

阶段一不直接学习完整的连续轨迹，而是学习可解释、可限制的离散参数向量：

```text
u = [粗加动作量, 缓补A动作量, 精加B基础脉冲, 最大补偿脉冲数, 收尾等待时间]
```

其中“动作量”可以是电机步数、振动时间、门阀开度时间或其组合；各设备适配层负责将统一动作量转换为设备命令。

## 4. 四段式实时控制

### 4.1 粗加

按 ILC 给出的粗加动作量快速接近目标。建议初始保守区间为目标质量的 70% 至 85%。实时称重达到粗加阈值或超过粗加最长时间时，立即切入缓补 A。

### 4.2 缓补 A

以较低速度和较小动作量接近目标。切段依据为预测尾量后的剩余质量，而不是仅依据当前瞬时质量：

`remaining_predicted = r - measured_mass - predicted_tail_mass`

当 `remaining_predicted` 小于精加阈值时，停止连续给粉并进入精加 B。

### 4.3 精加 B

使用受限的小脉冲或微振动，每个脉冲后必须等待天平采样窗口，并重新判断稳定性。精加的每一步均受最大单脉冲量、最大累计补偿量、最大脉冲数和任务超时限制。若配方禁止欠量，仍需保留足够的补偿机会；若存在过量上限，则以最小可控增量为决策下限。

### 4.4 收尾验收

停止给粉后，等待余粉完全落料或满足尾量外推条件。只有连续稳定窗口内的称重同时满足波动、漂移和持续时间要求，才将该质量作为 `y_k`。随后按配方规则判定合格、受控补偿、失败或人工复核。

## 5. 初版 ILC 更新策略

### 5.1 参数初始化（L0）

每个参数组由以下键唯一标识：

```text
粉体型号 + 粉体批次 + 给粉头型 + 目标质量区间 + 配方版本
```

首次任务使用人工标定得到的 L0 参数表。L0 只给出保守初值，不要求一次达到最优。

### 5.2 受限标量更新

阶段一先更新“总有效动作量”的补偿量，避免同时调整多个参数导致结果不可解释。令 `a_k` 为总有效动作量，初版更新为：

```text
a_(k+1) = clip(a_k + alpha * e_k / g_hat, a_min, a_max)
```

- `alpha`：学习增益，初始建议 0.2 至 0.5，并按粉体稳定性实验确定。
- `g_hat`：当前动作量到质量增量的局部增益估计（mg/动作单位），来自 L0 标定或近期有效样本。
- `clip`：动作量边界，防止单次学习带来过大变化。

正误差（欠量）增加下一次的前馈动作量，负误差（过量）减少下一次的前馈动作量。每次更新还必须受最大变化比例 `delta_a_max` 限制，例如不超过上一参数的 5% 至 10%。

### 5.3 分段参数分配

更新后的总动作量按固定或受控比例分配到粗加、缓补和精加：

```text
u_(k+1) = [p_coarse * a_(k+1), p_slow * a_(k+1), fine_pulse_base, n_fine_max, settle_time]
```

阶段一优先只学习粗加和缓补的前馈量；精加脉冲与稳定等待采用保守固定值。待积累足够数据后，再分别学习各段比例和尾量模型。

### 5.4 样本准入与冻结

仅在以下条件全部成立时，任务结果可进入 ILC 更新：

- 天平通信完整，零点与稳定判定有效。
- 无堵料、低流、门控异常、互锁触发或人工干预。
- 使用参数版本与配方版本可追溯。
- 最终质量未超过配方规定的硬性安全边界。

出现连续异常、误差明显恶化、粉体批次变更、头型更换或维护后，自动冻结 ILC 更新并回退到最近稳定的 L0/L1 参数版本，等待重新标定或人工确认。

## 6. 称重、尾量与稳定判定

ILC 的输入必须是可信的最终质量，因此称重逻辑独立于学习器实现。

### 6.1 采样数据

至少记录时间戳、原始质量、滤波质量、天平稳定标志、零点状态、给粉命令和门控状态。采样频率、滤波窗口、通信延迟和天平稳定标志由设备调研确定。

对于 AT8811/AT8812/AT8813 B/C 系列，适配层通过 Modbus RTU 读取实时重量寄存器 `0x0001`（2 个保持寄存器）和模块状态寄存器 `0x0003`。状态字的 bit 8 表示稳定、bit 9 表示零区；这两个硬件标志应作为软件稳定规则的输入，不能单独作为最终判稳依据。详细帧格式见 `at881x-modbus-rtu-spec.md`。

说明书只给出了实时重量的 32 位整数表示，未定义其相对于 mg 或 g 的缩放关系。因此，`raw_weight` 与 `mass_mg` 必须分开存储；上线前须以标准砝码确认 `scale_mg_per_count`，未确认时不得启用 ILC 更新或质量验收。

### 6.2 稳定规则初版

在长度为 `T_stable` 的连续窗口中，同时满足以下条件时判稳：

- 质量极差小于阈值 `epsilon_range`。
- 线性漂移斜率绝对值小于 `epsilon_slope`。
- 天平原生稳定标志持续有效（若设备提供）。
- 停止给粉后的最小等待时间已满足。

阈值暂由实验确定，并随目标量级、天平分辨率和环境振动水平写入配方或设备配置。

### 6.3 尾量外推

停止给粉后，通过近期质量变化计算尾量估计 `predicted_tail_mass`，仅用于提前切段和决定等待时长。最终验收必须以稳定实测质量为准。外推结果与实际尾量的偏差需入库，作为后续模型改进数据。

## 7. 状态机与异常策略

建议状态为：

```text
IDLE -> PRECHECK -> TARE -> COARSE -> SLOW_A -> FINE_B -> SETTLING -> ACCEPT
                                      |              |              |
                                      +------> FAULT <--------------+
ACCEPT -> LEARN -> ARCHIVE -> IDLE
FAULT  -> SAFE_STOP -> ARCHIVE -> IDLE
```

`LEARN` 只在 `ACCEPT` 后运行；其失败不得影响已经完成的任务结果。主要异常及默认策略如下：

| 异常 | 检测依据 | 默认处置 | 是否允许 ILC 更新 |
| --- | --- | --- | --- |
| 低流 | 动作后质量增量持续低于下限 | 有次数上限的重试，失败后安全退出 | 否 |
| 堵料 | 连续低流、驱动异常或传感器告警 | 停机、关闭门控、报警 | 否 |
| 超量 | 稳定质量超过硬上限 | 立即停止并标记失败/复核 | 否 |
| 稳定超时 | 未在最大等待时间内判稳 | 停机、保存原始数据、报警 | 否 |
| 天平通信异常 | 读数超时、校验失败或断线 | 禁止给粉，安全退出 | 否 |
| 执行器异常 | 命令未确认、超时或互锁触发 | 停机、报警 | 否 |

## 8. 数据模型与可追溯性

一条任务记录至少包含以下关联对象：

- `task`：任务 ID、配方、操作者、目标质量、开始结束时间、最终判定。
- `sample_trace`：原始与滤波称重时间序列、天平状态和环境信息。
- `command_trace`：每个执行命令、参数、确认结果和时间戳。
- `state_trace`：状态切换、原因、超时和重试次数。
- `alarm_trace`：报警码、严重级别、处置和人工操作。
- `parameter_snapshot`：L0/L1 参数、ILC 增益、边界、算法版本和配置哈希。
- `learning_record`：样本准入结果、误差、局部增益、更新前后参数及回退信息。

任何最终结果都必须能够回溯至所用参数快照和完整原始称重记录。

## 9. 阶段一实施步骤

1. 完成天平、给粉执行器、门控及安全互锁的接口调研与模拟适配层。
2. 采集无粉、连续给粉、停止落料和精加脉冲的基础数据，确定稳定判定与初版 L0 表。
3. 实现四段式状态机和所有硬性安全边界，先以固定 L0 参数完成闭环测试。
4. 实现受限标量 ILC、样本准入、参数版本化和自动冻结/回退。
5. 用重复任务验证收敛趋势、成功率、欠量率、过量上限和日志完整率。

## 10. 待调研并冻结的关键参数

以下参数必须由实验而非主观设定：

- 天平采样频率、通信时延、分辨率、稳定标志语义和漂移水平。
- 给粉动作单位、最小可控增量、动作到质量的局部增益及余粉落料分布。
- 粗加/缓补/精加切段阈值，稳定窗口和最大允许等待时间。
- 欠量、过量、总耗时、重试次数和异常退出的验收边界。
- ILC 学习增益、参数更新限幅、最小有效样本数及冻结/回退条件。

在这些参数冻结前，ILC 仅允许在仿真或受控标定模式下更新；生产任务使用经过审批的参数版本。
